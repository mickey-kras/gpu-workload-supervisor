# v0.1.17

The experimental LLM training tools can materialize recipes from inventoried local
assets, inspect trainer bindings and prepare private PEFT import plans. Import
preparation does not convert weights, register models or activate serving.

Training exports use provenance version 2, binding adapter and tokenizer files
before and after reload. Use the same supervisor release for training and import
preparation: provenance binds both the embedded worker and its source revision.
The tools reject old weight-only provenance. The `exportBytes` budget now covers the
adapter, configuration and saved tokenizer files together.

The Axolotl dependency lock targets the worker's local SFT with LoRA path and includes
explicit dependency deviations and an offline CPU smoke check. It does not qualify a GPU
runtime. No training preset is on. #453 remains open until the real-GPU evidence passes the checks in [LLM training qualification](../LLM-TRAINING-QUALIFICATION.md).
Checkpoint and resume (#454) and Training UI (#456) remain separate.
